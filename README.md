# 북오아시스 Plex 영상 재생 플러그인 (plex_player)

Plex 라이브러리를 선택해 영화/TV 영상을 앱 안에서 바로 재생하는 카테고리 레벨 플러그인입니다.

## 설치

1. `plugins/metadata/plex_player/` 폴더를 통째로 북오아시스 서버의 `plugins/metadata/` 아래에 복사합니다.
2. 서버를 재시작합니다.
3. 환경설정 > 플러그인 설정에서 "Plex 영상 재생" 플러그인을 활성화합니다.
4. 아래 값을 입력하고 저장합니다.
   - **Plex 서버 주소**: 예) `http://192.168.0.10:32400`
   - **Plex 토큰 (X-Plex-Token)**: Plex 계정/서버 토큰
   - 재생 해상도 / 최대 비트레이트(기본 8000kbps) / 자막 자동 합성 여부는 선택 사항
   - **표시할 라이브러리**: 기본은 비워두면 영화/TV 라이브러리 전체가 드롭다운에 보입니다.
     사이드바 라이브러리 드롭다운 옆의 톱니바퀴(⚙) 버튼을 누르면 체크박스로 원하는
     라이브러리를 고를 수 있습니다. "선택값 만들기"를 누르면 결과 문자열이 나오는데,
     이 값을 복사해서 이 화면의 텍스트 필드에 붙여넣고 저장하면 됩니다(체크박스가
     설정을 자동으로 저장하지는 않습니다 - 아래 "알아두면 좋은 점" 참고).
5. 좌측 사이드바에 "Plex 영상 재생" 메뉴가 생기며, 클릭하면 상단 드롭다운에서 Plex 라이브러리와
   정렬 방식(최신 등록순/가나다순 등)을 고를 수 있습니다.

## 재생을 위한 추가 설정 (중요)

실제 영상 스트리밍은 브라우저가 Plex 서버로 직접(코어의 스트리밍 프록시를 통해) 접속하므로,
**[설정 > 외부 도메인]** 탭에서 Plex 서버 주소(호스트 또는 IP)를 화이트리스트에 등록해야
재생 버튼을 눌렀을 때 실제로 재생됩니다. (예: `192.168.0.10` 또는 `plex.mydomain.com`)

- 라이브러리 목록/영상 목록 조회는 서버(플러그인 백엔드)가 직접 Plex API를 호출하므로
  화이트리스트 등록이 필요 없습니다.
- 오직 "재생" 단계(HLS 스트림)만 브라우저 → 코어 프록시 → Plex로 연결되며, 이 구간에만
  화이트리스트 등록이 필요합니다.

## 사용 흐름

1. 화면은 좌측 재생 영역 + 우측 목록 사이드바로 나뉩니다. 사이드바 좌측 가장자리의
   원형 화살표 버튼(&rsaquo;)을 눌러 목록을 접거나 펼칠 수 있습니다(선택 상태는
   다음 방문 때도 유지됩니다).
2. 사이드바 상단에서 라이브러리(영화/TV 쇼)와 정렬 방식을 선택하고, 검색창에
   제목을 입력하면 Plex 서버에서 바로 필터링된 결과를 보여줍니다.
3. 영화면 목록이 바로 뜨고, TV 쇼 라이브러리면 시리즈 목록이 뜹니다. 30개 단위로
   페이지네이션됩니다.
4. 시리즈 클릭 → 에피소드 목록으로 이동 (뒤로가기 버튼으로 복귀). 검색창은 지금
   보고 있는 목록(영화/시리즈 또는 에피소드) 안에서만 필터링됩니다.
5. 항목을 클릭하면 Plex의 Universal Transcode(HLS)로 인코딩된 스트림을 가져와
   좌측 재생 영역에서 hls.js로 바로 재생합니다. 재생창은 기본적으로 좌측 영역에
   크게 뜨고("인라인" 모드), 헤더의 "미니창" 버튼을 누르면 화면 구석의 작은 창으로
   전환되어 다른 카테고리로 이동해도 계속 재생됩니다(드래그로 위치 이동, 모서리로
   크기 조절 가능).

## 캐시 폴더 (Redis 불필요)

라이브러리 목록/썸네일 조회 결과는 코어의 Redis 캐시가 아니라, **이 플러그인 폴더 안
`cache/` 디렉토리**에 파일로 직접 캐싱됩니다(`cache/sections/`, `cache/thumbs/`). 배포
환경마다 코어의 Redis 캐시 헬퍼(`self.cache_get`/`cache_set`)가 실제로 있는지 불확실해서,
그것과 완전히 무관하게 항상 동작하도록 만들었습니다.

- 라이브러리 목록: 5분 캐시
- 썸네일: 30일 캐시
- 45일 넘은 캐시 파일은 쓰기 시점에 낮은 확률로 자동 정리됩니다(용량이 무한정 쌓이지 않음).
- 캐시를 강제로 비우고 싶으면 서버에서 `plugins/metadata/plex_player/cache/` 폴더를
  통째로 지워도 안전합니다(다음 요청 때 자동으로 다시 생성/조회됩니다).

## 알아두면 좋은 점

- **체크박스 라이브러리 선택기는 설정을 자동 저장하지 않습니다.** 이 플러그인은 코어의 정식
  설정 저장 API 없이 자체적으로 안전하게 값을 쓸 방법이 없어서, 체크박스는 항상 "결과
  문자열을 보여주기만" 하고 실제 저장은 사용자가 정식 설정 화면에서 직접 하도록 만들었습니다.
  (예전 버전에서 자동 저장을 시도했다가 기존 Plex 서버 주소/토큰 설정이 사라지는 사고가
  있었습니다 - 이 플러그인의 최신 버전을 쓰고 있다면 그 문제는 없습니다.)
- Plex 토큰을 얻는 방법은 Plex 공식 지원 문서의 "Finding an authentication token / X-Plex-Token"
  안내를 참고하십시오.
- 라이브러리 구성을 바꾼 직후에는 최대 5분까지 목록 반영이 늦을 수 있습니다(위 캐시 참고).
- 현재 구현은 영화(movie)와 TV 쇼(show/episode) 타입만 지원합니다. 음악 라이브러리 등은
  목록에 나타나지 않습니다.
- 자막을 화면에 합성(번인)하는 옵션을 켜두면 자막이 있는 영상은 항상 풀 트랜스코드가
  되어 서버 부하가 늘어납니다. 자막이 중요하지 않다면 꺼두는 것을 권장합니다.
