# 북오아시스 Plex 영상 재생 플러그인 (plex_player)

Plex 라이브러리를 선택해 영화/TV 영상을 앱 안에서 바로 재생하는 카테고리 레벨 플러그인입니다.

## 설치

1. `plugins/metadata/plex_player/` 폴더를 통째로 북오아시스 서버의 `plugins/metadata/` 아래에 복사합니다.
2. 서버를 재시작합니다.
3. 환경설정 > 플러그인 설정에서 "Plex 영상 재생" 플러그인을 활성화합니다.
4. 아래 값을 입력하고 저장합니다.
   - **Plex 서버 주소**: 예) `http://192.168.0.10:32400`
   - **Plex 토큰 (X-Plex-Token)**: Plex 계정/서버 토큰
   - 재생 해상도 / 최대 비트레이트는 선택 사항 (기본값: 1080p, 8000kbps)
   - **자막 자동 합성(번인)**: 기본은 "사용"이며, 영상에 자막이 있으면 화면에
     합성해서 보여줍니다. 다만 자막 번인은 항상 풀 트랜스코드를 강제하므로
     (Direct Stream 불가), 자막이 필요 없는 서재라면 "사용 안 함"으로 두는
     편이 재생이 더 가볍습니다.
5. 좌측 사이드바에 "Plex 영상 재생" 메뉴가 생기며, 클릭하면 상단 드롭다운에서 Plex 라이브러리를 고를 수 있습니다.

## 재생을 위한 추가 설정 (중요)

실제 영상 스트리밍은 브라우저가 Plex 서버로 직접(코어의 스트리밍 프록시를 통해) 접속하므로,
**[설정 > 외부 도메인]** 탭에서 Plex 서버 주소(호스트 또는 IP)를 화이트리스트에 등록해야
재생 버튼을 눌렀을 때 실제로 재생됩니다. (예: `192.168.0.10` 또는 `plex.mydomain.com`)

- 라이브러리 목록/영상 목록 조회는 서버(플러그인 백엔드)가 직접 Plex API를 호출하므로
  화이트리스트 등록이 필요 없습니다.
- 오직 "재생" 단계(HLS 스트림)만 브라우저 → 코어 프록시 → Plex로 연결되며, 이 구간에만
  화이트리스트 등록이 필요합니다.

## 사용 흐름

1. 상단 드롭다운에서 라이브러리(영화/TV 쇼) 선택
2. 옆의 "정렬" 드롭다운에서 가나다순/가나다 역순/최신 등록순/오래된
   등록순/최신 개봉순/오래된 개봉순 중 고를 수 있습니다(기본은 라이브러리
   기본 정렬). 시리즈 안 에피소드 목록에도 동일하게 적용됩니다. 정렬을
   바꾸면 1페이지로 돌아갑니다.
3. 영화면 바로 목록이 뜨고, TV 쇼 라이브러리면 시리즈 목록이 뜹니다.
   목록은 30개씩 페이지로 나뉘며, 화면 하단의 [1] [2] [3] ... 버튼으로
   이동할 수 있습니다.
4. 시리즈 클릭 → 에피소드 목록으로 이동 (뒤로가기 버튼으로 복귀, 에피소드
   목록도 동일하게 페이지네이션됩니다)
5. 영화/에피소드 카드를 클릭하면 Plex의 Universal Transcode(HLS)로 인코딩된 스트림을
   가져와 hls.js로 바로 재생합니다. 기본은 카테고리 페이지 안에서 크게
   재생되는 **인라인 모드**입니다(다른 카테고리로 이동하면 자연스럽게
   멈춥니다). 헤더의 **"미니창"** 버튼을 누르면 화면 우측 하단에 뜨는 작은
   창으로 전환되며, 이 모드에서는 다른 카테고리(도서 서재 등)로 이동해도
   영상이 계속 재생됩니다 - 헤더를 드래그해 위치 이동, 우하단 모서리로
   크기 조절도 가능합니다. 다시 "인라인으로" 버튼을 누르면 원래 페이지
   안으로 되돌아옵니다(단, plex_player 카테고리를 보고 있을 때만 가능).

## 알아두면 좋은 점

- Plex 토큰을 얻는 방법은 Plex 공식 지원 문서의 "Finding an authentication token / X-Plex-Token"
  안내를 참고하십시오.
- 목록 조회 결과는 5분간 캐시됩니다(Plex API 과다 호출 방지). 라이브러리 구성을 바꾼 직후에는
  최대 5분까지 반영이 늦을 수 있습니다.
- 현재 구현은 영화(movie)와 TV 쇼(show/episode) 타입만 지원합니다. 음악 라이브러리 등은
  목록에 나타나지 않습니다.
